# 믓 — MOVE & STRENGTH

**누구나 자기 방식대로 움직이고 강해지는 운동 기록 앱.**
마실처럼 가볍게, 쇠질처럼 진심으로. 슬로건은 **오늘도 좀 믓지게.**

| 항목 | 정의 |
| --- | --- |
| 한글 브랜드명 | 믓 |
| 영문 브랜드 메시지 | MOVE & STRENGTH (움직임과 근력). MEUT 같은 로마자 표기는 쓰지 않고, 영문은 설명·슬로건에만 쓴다 |
| 브랜드 심볼 | ㅁ+ㅅ, 철봉에 매달린 사람 |
| 브랜드 철학 | 마실처럼 가볍게, 쇠질처럼 진심으로 |
| 슬로건 | 오늘도 좀 믓지게. (보조: 내 방식대로, 내 몸답게. / 가볍게 나와, 제대로 들자. / STRONG ENOUGH TO BE YOURSELF.) |

## 로고 심볼

심볼은 글자 **믓** 그 자체다. 서체 **Pretendard Black**의 "믓" 글리프 윤곽을 그대로 도형으로 옮겨 썼다(SIL OFL 1.1, 윤곽을 로고로 쓰는 것 허용). 따라서 앱 제목이나 표지에 Pretendard 900으로 쓴 "믓"과 모양이 정확히 같다. 손으로 다시 그리거나 비율을 바꾸지 않는다.

- 넓고 납작한 **ㅁ**, 가장 긴 **ㅡ**, 넓게 벌어진 **ㅅ**. 철봉에 매달린 사람은 형태의 이야기로만 남긴다.
- **ㅡ만 펄스 틸**(`#4FB3A0`), ㅁ과 ㅅ은 배경에 따라 초크 화이트 또는 아이언 블랙. 몸의 중심선이자 철봉 한 줄이 브랜드 강조색이 된다.
- 64×64 그리드에 글자 높이 56(위아래 여백 4).

| 파일 (`brand/`) | 용도 |
| --- | --- |
| `meut-symbol-chalk.svg` | 어두운 배경 위 (기본) |
| `meut-symbol-iron.svg` | 밝은 배경 위 |
| `meut-app-icon.svg`, `meut-app-icon-180.png` | 앱 아이콘, 파비콘, 홈 화면 아이콘 |
| `meut-lockup-chalk.svg`, `meut-lockup-iron.svg` | 심볼 + MOVE & STRENGTH + 슬로건 가로 조합 |

- 최소 크기 24px.
- 여백은 심볼 높이의 1/4 이상.
- 색은 ㅡ = 펄스 틸, ㅁ·ㅅ = 초크 화이트(어두운 배경) 또는 아이언 블랙(밝은 배경)만 쓴다. 단색이 필요한 곳(도장, 1도 인쇄)은 ㅡ도 같은 색으로.
- 점·원 같은 추가 요소를 넣지 않는다.
- 기울이기, 외곽선만 남기기, 그라데이션, 그림자 금지.

## 컬러

블랙을 중심으로 한 스트리트 피트니스 감성. 형광색과 사이버펑크 톤은 피하고, 콘크리트·철봉·나무·흙에서 가져온 색을 쓴다. 순수한 #000 / #FFF는 쓰지 않는다.

| 토큰 | 값 | 역할 |
| --- | --- | --- |
| IRON BLACK `iron-black` | `#171717` | 메인 배경 |
| CHALK WHITE `chalk-white` | `#F2F0E9` | 기본 글자, 강조 카드 바탕 |
| FIELD GREEN `field-green` | `#B5C49C` | 운동 상태 (운동한 날, 세트 번호, 근육량) |
| PULSE TEAL `pulse-teal` | `#4FB3A0` | 강조 요소 (주 버튼, 오늘, PT, 포커스, 심볼의 ㅡ) |
| CONCRETE `concrete` | `#77736D` | 아이콘·구분 요소. 작은 글자에는 `ink-muted` 사용 |
| GRAPHITE `graphite` | `#333333` | 구분선, 컨트롤 테두리 |

**사용 비율**: 블랙 55% · 아이보리 30% · 그린 10% · 틸 5%. 틸은 화면당 한두 곳(주 버튼, 오늘 표시)에만.

강조색은 운동·건강에 어울리도록 러스트 오렌지에서 **펄스 틸**로 바꿨다. 필드 그린(운동 상태)과는 명도 차이(0.36 vs 0.52)로 구분된다.

**경고**(통증·부상 언급, DB 안내)는 강조색과 겹치지 않게 머스터드 `#D9A05B`를 쓴다.

**부드러운 변형** (넓은 면적, 인쇄물): 차콜 `#191919` · 웜 아이보리 `#F2F0E9` · 세이지 `#A8B59A`. 앱 UI에서는 기본 팔레트를 쓴다.

**대비 규칙**
- CONCRETE `#77736D`는 아이언 블랙 위에서 3.8:1이라 본문 글자로는 부족하다. 보조 글자는 `ink-muted` `#9A958D`(6.0:1)를 쓴다.
- 펄스 틸 위 글자는 아이언 블랙(7.1:1). 초크 화이트 위에 틸 글자는 2.2:1이라 금지(밝은 바탕에서는 틸을 면으로만 쓴다).
- 필드 그린 위 글자도 아이언 블랙(9.7:1).
- 강조 카드(초크 화이트 바탕) 안에서는 글자 `#171717`, 보조 글자 `#5F5B55`(5.9:1).

## 타이포그래피

| 용도 | 방향 | 서체 |
| --- | --- | --- |
| 브랜드명 | 두꺼운 고딕 | 심볼 사용, 텍스트일 때 Pretendard 900 |
| 앱 제목 | 단단한 산세리프 | Pretendard 800, 28px |
| 운동 기록·숫자 | 숫자가 명확한 고딕 | Pretendard 800, tabular-nums, 32–48px |
| 영문 보조 | 모노스페이스 | IBM Plex Mono 500/700, 대문자 + 자간 0.12–0.16em |
| 설명 문구 | 가독성 높은 본문 고딕 | Pretendard 400, 15px / 22px |

모노스페이스는 짧은 영문 라벨(TODAY, LOG, HISTORY, MOVE & STRENGTH), 날짜 구분선, 세트 번호, 강사 코드에만 쓴다. 화면 전체가 기술 문서처럼 보이지 않게, 본문과 버튼은 항상 Pretendard.

## 레이아웃과 컴포넌트 규격

| 항목 | 규격 |
| --- | --- |
| 화면 좌우 여백 | 20px |
| 기본 간격 | 8px 단위 (8 / 16 / 24 / 32 / 48) |
| 버튼 높이 | 48–52px, 직사각형, 모서리 6px |
| 입력 영역 | 48px 이상 |
| 카드 | 바탕 `#222222`, 테두리 GRAPHITE 1px, 패딩 16–20px, 모서리 6px |
| 칩·태그 | 모서리 4px (알약형 금지) |
| 페이지 제목 | 28–36px |
| 주요 숫자 | 32–48px |
| 아이콘 | 24px 그리드, 2px 라인, 각진 끝 |
| 애니메이션 | 짧고 묵직하게 (120–180ms, ease-out). 튕기는 효과 없음 |
| 사진 | 실제 운동 공간과 사람. 스톡 느낌의 과장된 연출은 피함 |

- **주 버튼**: 펄스 틸 바탕 + 아이언 블랙 글자. 화면당 하나.
- **선택된 칩·세그먼트**: 초크 화이트 바탕 + 아이언 블랙 글자.
- **강조 카드**: 초크 화이트 바탕(트레이너 노트, 종목 요약, 내 정보 등). 화면당 한두 장.
- **상태 점**: 운동 = 그린, PT = 틸, 인바디 = 초크. 4px 모서리의 작은 사각형.
- 이모지는 UI 표식으로 쓰지 않는다. 아이콘은 라인 아이콘 또는 자체 심볼.

## 말투와 카피

친구처럼 편하지만 운동에 대해서는 진심인 태도. 너무 친절하거나 지나치게 전문적인 말투는 피한다.

| 상황 | 카피 |
| --- | --- |
| 앱 첫 화면 | 오늘도 좀 들어볼까? |
| 운동 시작 | 자, 쇠질하러 가자. |
| 운동 완료 | 오늘도 한 건 했다. |
| 기록 달성 (최고 무게 경신) | 오, 이건 좀 믓지다. |
| 장기간 미접속 (7일 이상) | 쇠가 기다린다. |
| 운동 인증 / 트레이너 수업 기록 | 오늘의 쇠질 완료. |
| 커뮤니티 | 잘하든 못하든 일단 들자. |
| 개인 기록 | 남과 비교 말고 어제의 나와 비교. |

오류 문구는 카피 톤을 빼고, 무엇이 잘못됐고 어떻게 하면 되는지만 쓴다.

## 앱 적용 (index.html)

`index.html`의 `:root` 토큰이 이 문서의 컬러·규격을 그대로 따른다. `--iron`, `--chalk`, `--green`, `--accent`(펄스 틸), `--concrete`, `--graphite`가 원색이고, 화면은 `--bg`, `--card`, `--card2`, `--line`, `--t`, `--m`, `--p`(= 펄스 틸) 같은 역할 토큰으로만 색을 쓴다. 새 화면을 만들 때도 원색 hex를 직접 쓰지 말고 역할 토큰을 쓴다.
